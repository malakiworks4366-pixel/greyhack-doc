## Featured tools

| Tool | Author | What it is |
|---|---|---|
| 5hell | Plu70 | The best-known all-in-one shell emulator and multitool, with 100+ commands |
| Greybel JS | ayecue | A CLI toolkit for GreyScript: bundler, minifier, interpreter, REPL and debugger |
| Greybel VS | ayecue | A VS Code extension: autocomplete, diagnostics, debugging, and building in-game |
| Kore | Plu70 | 5hell's setup and automation helper |
| Glosure | Maho_citrus | A LISP-like language that runs code at runtime without recompiling |
| Airlink | VauL7Zer0 | A keyboard-driven Wi-Fi cracking terminal UI |
