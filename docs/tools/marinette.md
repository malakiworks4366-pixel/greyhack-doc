## What it is

Marinette is a small, approachable shell configured through Glosure scripts rather than compiled GreyScript. Because it's Glosure-based, it integrates naturally with [5hell](5hell.md)'s `macro` system and can be tweaked at runtime.

If you want a lightweight, readable shell to learn from or extend, Marinette is a good starting point. For a maximal, do-everything environment, see [5hell](5hell.md); for a bash replacement, see [FancyBash](fancybash.md).
