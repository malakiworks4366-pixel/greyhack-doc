# FancyBash

<span class="gh-badge">Shell</span>

**FancyBash** is a feature-rich drop-in replacement for Grey Hack's default `bash`, by **siasur**. It improves the day-to-day shell experience without the scope of a full framework like [5hell](5hell.md).

## Features

- **`.bashrc` support.** Define a `PATH` variable in your home directory's `.bashrc` so you can run executables without typing full paths.
- **Enhanced prompt.** A nicer prompt, with more customisation planned.

## Installation

=== "With Greybel"

    Open the project in VS Code with [Greybel VS](greybel-vs.md); it generates an installer file you import into the game.

=== "Manual"

    Adjust the files for Grey Hack's requirements, making sure all `import_code` calls are in the entry file, then build in the CodeEditor.

!!! note
    FancyBash is specific to Grey Hack and not a real-world shell.
