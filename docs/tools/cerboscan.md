# CerboScan

<span class="gh-badge">Utility</span> <span class="gh-badge">Scanner</span>

**CerboScan** is a LAN network scanner for Grey Hack. It enumerates the devices on a local network and reports what it finds.

## Features

- Detects firewalls, servers, and ADB devices, printing their LAN IPs.
- Skips switches during scanning and lists them separately.
- Supports port **5555** / ADB scanning.

## Limitation

> "This only can scan devices connected to a router and not devices connected to a Switch."

## Installation

The repository contains a single `CerboScan` binary in the main branch — clone or download it and run it in-game. For the networking concepts it relies on, see [Networking Basics](../gameplay/networking.md).
