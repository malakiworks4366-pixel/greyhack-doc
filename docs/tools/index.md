# Player Tools

Grey Hack ships with basic programs, so the community has built a rich ecosystem on top of GreyScript. This directory documents the most popular and influential player-made tools.

!!! note "Credit & accuracy"
    Every tool here belongs to its author. We summarise what each does and how to install it, and link to the source repository and Discord where available. For the latest version and the exact game build a tool supports, always check its repository. If something is out of date, [contribute a fix](../community/contributing.md).

## Development

Tools for writing, building, and debugging GreyScript.

| Tool | Author | Summary |
|---|---|---|
| [Greybel JS](greybel-js.md) | ayecue | CLI toolkit: bundler, minifier, interpreter, REPL, debugger |
| [Greybel VS](greybel-vs.md) | ayecue | VS Code extension with autocomplete, debugging, in-game builds |
| [GreyScript (VS Code)](greyscript-vscode.md) | WyattSL | Lightweight VS Code syntax/highlighting extension |
| [GreyScript Prime](greyscript-prime.md) | Svarii | SDK of helper methods for objects, text, math, files |
| [Message Hook & BepInEx Mods](mods.md) | various | Native mods that extend the game client |
