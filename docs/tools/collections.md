# Script Collections

Beyond the headline tools, many players publish grab-bag repositories of scripts worth browsing for ideas and utilities. These vary in polish and in which game version they target, so read each repo's notes.

| Repository | Author | Notes |
|---|---|---|
| [psimonson/greyhack-scripts](https://github.com/psimonson/greyhack-scripts) | psimonson | A large, popular collection organised by game version (v0.7, v0.8). |
| [corvusw/GHPublic](https://github.com/corvusw/GHPublic) | Corvus | ~13 focused `.ms` tools: `metaMonitor`, `playerFinder`, `shellAttack`, `wifi`, `corruptLogs`, and more. |
| [irtsa-dev/greyscript-tools](https://github.com/irtsa-dev/greyscript-tools) | irtsa-dev | Assorted utilities; same author's [grsa](https://github.com/irtsa-dev/grsa) does RSA in GreyScript and [bltings](https://github.com/irtsa-dev/bltings) adds helper functions. |
| [xxPhilipxx/GreyHack](https://github.com/xxPhilipxx/GreyHack) | xxPhilipxx | Tool source codes ([legacy mirror](https://github.com/NTF121/xxPhilipxx-GreyHack-Legacy)). |
| [rmb938/greyhack-game-scripts](https://github.com/rmb938/greyhack-game-scripts) | rmb938 | Personal scripts and libraries. |
| [ftzi/grey-hack](https://github.com/ftzi/grey-hack) | ftzi | Scripts with a Greybel watch-mode setup. |
| [DarkEye123/grey-hack](https://github.com/DarkEye123/grey-hack) | DarkEye123 | A handful of learning scripts. |
| [salmon85/Grey_hack_scripts](https://github.com/salmon85/Grey_hack_scripts) | salmon85 | Public scripts the author uses. |
| [MrMime0x0](https://github.com/MrMime0x0) | MrMime0x0 | Many proof-of-concepts: `GreyAI`, `GreyMail`, `ssh-worm`, `connectX`, `RunAfterError`, plus [CerboScan](cerboscan.md). |

## Repository / sharing platforms

- **[Grey Repo](https://www.greyrepo.xyz/)** — a website for sharing and discovering Grey Hack scripts.
- **[Roupiye/grey-hack-repo](https://github.com/Roupiye/grey-hack-repo)** — a community repository for sharing scripts.
