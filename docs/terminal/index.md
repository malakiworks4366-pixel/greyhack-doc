# Terminal

The terminal is where most of Grey Hack happens. This section documents the built-in commands and the `apt-get` package manager.

| Page | Covers |
|---|---|
| [Command Reference](commands.md) | Every built-in terminal command |
| [Package Manager (apt-get)](apt.md) | Installing libraries and programs from repositories |

!!! tip
    Run `help` in-game at any time to list available commands, and `<command> -h` for usage on many of them. Community shells such as [5hell](../tools/5hell.md) and [FancyBash](../tools/fancybash.md) replace the default shell with far more capable ones.
