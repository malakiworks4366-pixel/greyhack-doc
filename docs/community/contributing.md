# Contributing

This documentation is community-maintained and open to fixes and additions. Grey Hack changes often, and there are always more tools to cover.

## Ways to help

- **Fix outdated info.** Game versions, tool commands, and ports change. If something is wrong, correct it.
- **Add a tool.** Found a popular tool that isn't here? Add a page under `docs/tools/` and link it from the [directory](../tools/index.md).
- **Improve guides.** Clearer explanations and examples are always welcome.

## How the site is built

The site uses [MkDocs](https://www.mkdocs.org/) with the [Material](https://squidfunk.github.io/mkdocs-material/) theme.

```bash
# clone, then:
pip install -r requirements.txt
mkdocs serve          # live preview at http://127.0.0.1:8000
mkdocs build --strict # what CI runs
```

- Pages live in `docs/` as Markdown.
- Navigation is defined in `mkdocs.yml`.
- The [API Overview](../greyscript/api-overview.md) is generated by `scripts/gen_api_overview.py` from [ayecue/greyscript-meta](https://github.com/ayecue/greyscript-meta); don't edit it by hand — regenerate it.

## Making a change

1. Edit or add Markdown under `docs/`.
2. Add new pages to the `nav:` in `mkdocs.yml`.
3. Run `mkdocs build --strict` to catch broken links and bad config.
4. Commit and open a pull request.

## Style

- Keep an unofficial, neutral, reference tone.
- Credit tool authors and link to their repositories.
- Prefer describing what tools do and how to install/use them over step-by-step attack walkthroughs.

## Deployment

Pushing to `main` triggers `.github/workflows/pages.yml`, which builds the site and deploys it to GitHub Pages.
