## Places to go

| Resource | What it is |
|---|---|
| [Grey Hack on Steam](https://store.steampowered.com/app/605230/Grey_Hack/) | The game, its forums, and official guides |
| [Steam Community guides](https://steamcommunity.com/app/605230/guides/) | Player-written tutorials |
| [documentation.greyscript.org](https://documentation.greyscript.org) | The canonical GreyScript API docs (ayecue) |
| [editor.greyscript.org](https://editor.greyscript.org) | In-browser GreyScript editor |
