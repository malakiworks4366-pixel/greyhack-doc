# What is Grey Hack?

**Grey Hack** is a hacking simulation game by **Loading Home**, available on [Steam](https://store.steampowered.com/app/605230/Grey_Hack/). You get a simulated Linux-like desktop, a terminal, and a whole procedurally generated internet full of computers, routers, and services to explore.

## Key ideas

- **A simulated internet.** Every IP address you meet belongs to a generated network with routers, switches, servers, and personal computers. Each one runs services on ports, backed by libraries that have versions and vulnerabilities.
- **GreyScript.** The game has its own programming language, based on [MiniScript](https://miniscript.org/). You write it in the in-game CodeEditor and compile it into binaries. Most serious players automate everything.
- **Persistent multiplayer.** In multiplayer, other players share the world with you. They can attack your machine, and you can attack theirs.
- **Single player.** An offline world to learn in at your own pace, with the same mechanics.

## Modes

| Mode | Description |
|---|---|
| Single player | An offline, private world. The best place to learn and test tools. |
| Multiplayer | A shared persistent world with other players. |
| Nightly / test builds | Optional beta branches where API changes often land first. |

## Why player tools matter

The game's built-in programs are deliberately basic. The community has built shells, frameworks, editors, debuggers, and whole programming languages on top of GreyScript. Those tools are what the Player Tools section documents.

!!! info "Game versions"
    Grey Hack is still developed actively, and the GreyScript API changes between versions. Check each tool's repository for the game version it supports.
